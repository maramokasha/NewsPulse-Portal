# NewsPulse-Portal

A PHP & MySQL news management system. Registered users can manage news articles and categories, upload images, soft-delete and restore articles, and print their news list.

## Features
- User registration, login and logout
- Create and view categories
- Create, edit, view and print news articles
- Image upload for articles
- Soft delete and restore of news articles
- Dashboard with light/dark theme
